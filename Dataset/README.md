# Dataset

This folder contains information about the dataset used for the Blinkit Grocery Sales Analysis project.

## Dataset Details

- Dataset: Blinkit Grocery Sales Data
- Records: 8,523
- Database: SQL Server
- Table: `BlinkIT Grocery Data`

## Columns

The dataset contains the following columns:

- Item_Fat_Content
- Item_Identifier
- Item_Type
- Outlet_Establishment_Year
- Outlet_Identifier
- Outlet_Location_Type
- Outlet_Size
- Outlet_Type
- Item_Visibility
- Sales
- Rating

## Note

The original CSV dataset is not included in this repository. The SQL analysis was performed using the dataset imported into SQL Server.
